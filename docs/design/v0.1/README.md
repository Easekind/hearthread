# hearthread v0.9

[打开单文件交互稿](index.html)。本版基于 v0.8 的演示书库制作，资源已嵌入 HTML，双击即可离线体验。

默认浅色，选中的书在底部浮动阅读栏显示微缩封面。界面采用平台系统字体，书库标题、书名和辅助信息分别调整字距与行高。设置中可切换纸色和深色。

桌面设置面板从右侧进出，手机从底部升起。拖动手机面板顶部的把手可改变位置，松手时根据当前位置和速度决定归位或关闭。回弹途中可再次抓取。开启减少动态效果后，打开和关闭即时完成；减少透明度和增强对比度使用实色工具栏与面板。

运行 `node docs/design/v0.9/build.mjs` 可从 v0.8 和本目录的样式、手势脚本重建交互稿。本地预览命令为 `python3 -m http.server 4182 --bind 127.0.0.1 --directory docs/design/v0.9`。

书库搜索匹配中英文书名与作者。分类、排序和书目操作菜单可用方向键选择、Enter 确认、Esc 收起。点击「管理藏书」进入批量选择，完成后回到原来的视图。导入面板支持多选或拖放文件，确认后会把书目加入所选分类，仅在本次页面会话有效。

[打开阅读样张](index.html#read-1) 或 [打开设置](index.html#settings)。进入阅读后只显示正文，轻点页面呼出工具，再点收起。键盘可用 Tab 找到「显示阅读工具」，或在阅读层按 Enter 切换。设置中的字号、行距和字体与阅读页共享，修改即时体现在样文中。EPUB、PDF 和 Markdown 均为内嵌排版样张，阅读位置和偏好保留在本次页面会话。

书库中的导入、导出、移动、管理和排序使用独立图标。选书时仅更新选中状态与底部阅读栏。菜单从触发处展开，可直接切换；对话框关闭时立即归还焦点。键盘导航和快捷键即时生效，触控与鼠标保留短过渡。从书墙或列表打开书籍时，当前封面从书脊处轻轻翻开，阅读页面和正文依次淡入，全程约 300 毫秒。返回时以原书封面为落点。

在分类内清除搜索会保留当前分类。列表行可直接打开书籍，批量管理时点击行可切换选择。导入前会汇总待导入和跳过的文件。书内搜索结果支持回到正文定位匹配词，再次展开搜索可接着查看本书的结果。桌面设置分类可用上下方向键切换。删除提示在页面切到后台或「撤销」按钮获得键盘焦点时暂停计时。
